# Политика безопасности

## Что делает проект

`flask-i18n` — минимальный модуль интернационализации на Python плюс расширение
для Flask. Читает JSON-файлы переводов с диска, хранит выбранный язык в сессии
Flask. Сетевых запросов не делает.

## Поддерживаемые версии

Поддерживается ветка `main`.

## Что считается уязвимостью

В области действия:

- path traversal через `load()` / `load_dir()` при подстановке пользовательских
  путей;
- подстановка в `str.format()` через параметры `t()` (например доступ к
  атрибутам объектов через `{0.__class__}`);
- XSS в шаблонах из-за неэкранированного результата `t()`;
- фиксация языка из недоверенного `?lang=` в сессии.

Вне области действия:

- уязвимости Flask и других зависимостей;
- последствия того, что приложение пользователя вставляет переводы через
  `|safe` или `innerHTML`.

## Как сообщить

Не открывайте публичный issue. Используйте приватный канал GitHub:

1. Вкладка **Security** → **Report a vulnerability** (GitHub Security Advisories).
2. Укажите версию или коммит, версию Python и Flask, шаги воспроизведения,
   ожидаемое и фактическое поведение.

Подтверждаем получение в течение 7 дней, исправление стараемся выпустить в
течение 30 дней. Bug bounty нет.
